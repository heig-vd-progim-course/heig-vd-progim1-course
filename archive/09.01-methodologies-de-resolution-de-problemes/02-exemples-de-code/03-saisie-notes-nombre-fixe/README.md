## Description

Cette troisième étape ajoute l'interaction avec l'utilisatrice. Au lieu de
définir les notes directement dans le code, le programme demande à
l'utilisatrice de saisir les notes au clavier.

Le programme :

- Demande à l'utilisatrice de saisir 5 notes (nombre fixe)
- Utilise la classe `Scanner` pour lire les entrées
- Stocke les notes dans un tableau
- Affiche les notes saisies
- Calcule et affiche le minimum, maximum et moyenne

Cette version introduit la notion d'entrée-sortie interactive et montre comment
valider les données saisies.

## Compilation et exécution

```bash
javac Main.java
java Main
```
