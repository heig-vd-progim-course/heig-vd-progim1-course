## Description

Cette quatrième étape améliore le programme en permettant à l'utilisatrice de
choisir le nombre de notes à saisir. Le programme devient ainsi plus flexible et
adaptable.

Le programme :

- Demande à l'utilisatrice combien de notes elle souhaite saisir
- Valide que le nombre est positif
- Crée un tableau de la taille appropriée
- Demande la saisie de chaque note
- Affiche les notes saisies
- Calcule et affiche le minimum, maximum et moyenne

Cette version montre comment créer des tableaux de taille dynamique en fonction
des besoins de l'utilisatrice.

## Compilation et exécution

```bash
javac Main.java
java Main
```
