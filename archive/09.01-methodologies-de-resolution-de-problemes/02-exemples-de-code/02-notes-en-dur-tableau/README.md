## Description

Cette deuxième étape utilise un tableau pour stocker les notes au lieu de
variables individuelles. Cela simplifie considérablement le code et permet de
gérer facilement un nombre variable de notes.

Le programme :

- Déclare un tableau de 5 notes initialisées avec des valeurs
- Affiche les notes avec une boucle for classique
- Affiche les notes avec une boucle for-each
- Calcule et affiche le minimum, maximum et moyenne des notes

Cette version montre l'avantage des tableaux : le code est plus court, plus
lisible et plus facile à maintenir.

## Compilation et exécution

```bash
javac Main.java
java Main
```
