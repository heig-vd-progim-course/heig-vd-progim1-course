# Exemple : Notes en dur avec variables individuelles

Cet exemple illustre la version la plus simple du programme de gestion de notes
avec :

- Variables individuelles pour chaque note (pas de tableaux)
- Affichage individuel de chaque note
- Calcul de la moyenne
- Tout le code dans la fonction `main`

## Compilation et exécution

```bash
javac Main.java
java Main
```
