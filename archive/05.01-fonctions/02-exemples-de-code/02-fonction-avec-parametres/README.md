# Exemple : Fonction avec paramètres

Cet exemple illustre l'utilisation de paramètres dans les fonctions avec :

- Déclaration de fonctions avec un ou plusieurs paramètres
- Passage de valeurs lors de l'appel
- Utilisation des paramètres dans le corps de la fonction
- Différents types de paramètres (`int`, `String`, `double`)

## Compilation et exécution

```bash
javac Main.java
java Main
```
