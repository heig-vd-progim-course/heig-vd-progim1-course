# Exemple : Fonction simple

Cet exemple illustre la création et l'appel d'une fonction de base avec :

- Déclaration d'une fonction simple sans paramètres
- Mot-clé `static` pour les fonctions de classe
- Appel d'une fonction depuis `main`
- Fonction avec type de retour `void` (ne retourne rien)

## Compilation et exécution

```bash
javac Main.java
java Main
```
