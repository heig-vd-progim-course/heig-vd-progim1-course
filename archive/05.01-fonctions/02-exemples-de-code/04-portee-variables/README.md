# Exemple : Portée des variables

Cet exemple illustre le concept de portée (scope) des variables avec :

- Variables locales : déclarées dans une fonction, accessibles uniquement dans
  celle-ci
- Paramètres : variables locales passées à la fonction
- Variables locales dans `main`
- Impossibilité d'accéder aux variables locales d'une autre fonction

## Compilation et exécution

```bash
javac Main.java
java Main
```
