# Exemple : Fonction avec valeur de retour

Cet exemple illustre les fonctions qui retournent une valeur avec :

- Déclaration avec type de retour (`int`, `double`, `boolean`, `String`)
- Mot-clé `return` pour renvoyer un résultat
- Stockage du résultat dans une variable
- Utilisation directe du résultat dans une expression

## Compilation et exécution

```bash
javac Main.java
java Main
```
