# Exemple : Tableau irrégulier

Cet exemple illustre l'utilisation de tableaux irréguliers (jagged arrays) avec
:

- Création d'un tableau 2D avec des lignes de longueurs différentes.
- Planning hebdomadaire avec un nombre d'heures variable par semaine.
- Calcul de statistiques sur un tableau irrégulier.
- Parcours sécurisé en vérifiant la longueur de chaque ligne.

## Compilation et exécution

```bash
javac Main.java
java Main
```
