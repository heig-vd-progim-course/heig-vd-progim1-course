# Exemple : Tableau à deux dimensions

Cet exemple illustre l'utilisation de tableaux multidimensionnels avec :

- Création d'un tableau 2D (matrice).
- Accès aux éléments avec deux indices.
- Parcours avec boucles imbriquées.
- Application pratique : grille de morpion.

## Compilation et exécution

```bash
javac Main.java
java Main
```
