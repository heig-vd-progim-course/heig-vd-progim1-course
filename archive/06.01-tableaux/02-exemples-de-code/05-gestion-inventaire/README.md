# Exemple : Gestion d'inventaire

Cet exemple illustre une application pratique des tableaux avec :

- Gestion d'un inventaire de produits.
- Recherche d'un produit par nom.
- Calcul de la valeur totale de l'inventaire.
- Mise à jour des quantités en stock.
- Utilisation de tableaux parallèles (noms, quantités, prix).

## Compilation et exécution

```bash
javac Main.java
java Main
```
