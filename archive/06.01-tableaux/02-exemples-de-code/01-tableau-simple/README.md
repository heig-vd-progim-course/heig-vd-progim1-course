# Exemple : Tableau simple

Cet exemple illustre la création et l'utilisation basique d'un tableau avec :

- Déclaration et initialisation d'un tableau.
- Accès aux éléments par index.
- Modification d'un élément.
- Affichage de la taille du tableau avec `length`.

## Compilation et exécution

```bash
javac Main.java
java Main
```
