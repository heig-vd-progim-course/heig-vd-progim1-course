# Exemple : Utilisation de la classe Arrays

Cet exemple illustre les méthodes utilitaires de la classe `Arrays` avec :

- `Arrays.toString()` pour afficher un tableau.
- `Arrays.sort()` pour trier un tableau.
- `Arrays.copyOf()` pour copier un tableau.
- `Arrays.fill()` pour remplir un tableau.
- `Arrays.equals()` pour comparer deux tableaux.

## Compilation et exécution

```bash
javac Main.java
java Main
```
