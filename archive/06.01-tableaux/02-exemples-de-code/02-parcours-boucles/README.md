# Exemple : Parcours avec différentes boucles

Cet exemple illustre les différentes façons de parcourir un tableau avec :

- Boucle `for` classique avec index.
- Boucle `for-each` pour un parcours simple.
- Boucle `while` pour un parcours conditionnel.
- Calcul de statistiques simples (somme, moyenne, maximum).

## Compilation et exécution

```bash
javac Main.java
java Main
```
