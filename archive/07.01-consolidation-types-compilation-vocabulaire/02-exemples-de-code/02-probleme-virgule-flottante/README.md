# Exemple : Problème de virgule flottante

Cet exemple illustre les limites de la représentation des nombres à virgule
flottante avec :

- La démonstration du problème 0.1 + 0.2 ≠ 0.3
- L'explication du standard IEEE 754
- Les bonnes pratiques pour comparer des nombres flottants
- Une introduction à BigDecimal pour les calculs précis

Pour compiler et exécuter :

```bash
javac FloatingPointProblem.java
java FloatingPointProblem
```
