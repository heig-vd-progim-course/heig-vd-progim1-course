# Exemple : Arguments en ligne de commande

Cet exemple illustre comment recevoir et utiliser des arguments passés au
programme avec :

- Le rôle du tableau `String[] args`
- L'accès aux différents arguments
- La vérification de la présence d'arguments
- Des exemples pratiques d'utilisation

Pour compiler et exécuter :

```bash
# Compilation
javac CommandLineArguments.java

# Exécution sans arguments
java CommandLineArguments

# Exécution avec des arguments
java CommandLineArguments Ariel Nox Amaru
```
