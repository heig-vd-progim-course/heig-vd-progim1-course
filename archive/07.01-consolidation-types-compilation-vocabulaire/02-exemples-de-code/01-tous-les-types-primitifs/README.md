# Exemple : Tous les types primitifs

Cet exemple illustre les 8 types primitifs disponibles en Java avec :

- Les types entiers (byte, short, int, long)
- Les types à virgule flottante (float, double)
- Le type booléen (boolean)
- Le type caractère (char)

Pour compiler et exécuter :

```bash
javac AllPrimitiveTypes.java
java AllPrimitiveTypes
```
