# Exemple : Structure d'un programme Java

Cet exemple illustre la structure minimale d'un programme Java avec :

- Le rôle de `public class`
- La correspondance entre le nom du fichier et le nom de la classe
- Le point d'entrée `main`
- Une introduction légère aux classes

Pour compiler et exécuter :

```bash
javac JavaStructure.java
java JavaStructure
```
