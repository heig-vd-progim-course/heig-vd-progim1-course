# Exemple : Programme interactif simple

Cet exemple illustre la création d'un programme interactif complet avec :

- Combinaison de `System.out` et `Scanner`
- Menu avec choix utilisateur
- Boucle pour répéter l'interaction
- Validation des entrées
- Structure d'un programme conversationnel

## Compilation et exécution

```bash
javac Main.java
java Main
```
