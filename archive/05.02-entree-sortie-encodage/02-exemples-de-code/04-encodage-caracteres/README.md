# Exemple : Encodage de caractères

Cet exemple illustre les concepts d'encodage des caractères avec :

- Affichage de caractères spéciaux (accents, symboles)
- Codes ASCII et Unicode
- Conversion entre `char` et codes numériques
- Caractères de différentes langues et alphabets

## Compilation et exécution

```bash
javac Main.java
java Main
```

## Note importante

Pour que les caractères spéciaux s'affichent correctement, assurez-vous que :

- Votre terminal utilise l'encodage UTF-8
- Votre fichier source est sauvegardé en UTF-8
