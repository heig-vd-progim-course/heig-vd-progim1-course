# Exemple : Quiz interactif complet

Cet exemple illustre un programme complet combinant tous les concepts avec :

- Interface utilisateur riche avec menus
- Gestion de questions-réponses
- Calcul de score
- Validation des entrées
- Feedback interactif
- Structure modulaire avec fonctions

## Compilation et exécution

```bash
javac Main.java
java Main
```
