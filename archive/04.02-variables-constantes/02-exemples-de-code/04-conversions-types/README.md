# Exemple : Conversions de types

Cet exemple illustre la conversion entre différents types de données avec :

- Conversion implicite (widening) : petits types vers grands types
- Conversion explicite (casting) : grands types vers petits types
- Conversion entre `int` et `double`
- Risques de perte de données lors des conversions

## Compilation et exécution

```bash
javac Main.java
java Main
```
