# Exemple : Opérateurs arithmétiques

Cet exemple illustre l'utilisation des opérateurs arithmétiques en Java avec :

- Addition (+), soustraction (-), multiplication (\*), division (/)
- Modulo (%) pour obtenir le reste d'une division
- Opérateurs d'incrémentation (++) et de décrémentation (--)
- Ordre de priorité des opérations

## Compilation et exécution

```bash
javac Main.java
java Main
```
