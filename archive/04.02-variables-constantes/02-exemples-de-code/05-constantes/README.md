# Exemple : Constantes

Cet exemple illustre l'utilisation des constantes en Java avec :

- Déclaration de constantes avec `final`
- Convention de nommage (MAJUSCULES_AVEC_UNDERSCORE)
- Avantages des constantes pour la lisibilité et la maintenance
- Utilisation de constantes dans des calculs

## Compilation et exécution

```bash
javac Main.java
java Main
```
