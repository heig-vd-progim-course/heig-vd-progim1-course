# Exemple : Types primitifs

Cet exemple illustre l'utilisation des types de données primitifs en Java avec :

- Types entiers (`int`, `long`)
- Types décimaux (`double`)
- Type booléen (`boolean`)
- Type caractère (`char`)
- Affichage des valeurs avec `System.out.println`

## Compilation et exécution

```bash
javac Main.java
java Main
```
