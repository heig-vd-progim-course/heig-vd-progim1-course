# Exemple : Imports basiques

Cet exemple illustre l'utilisation des imports en Java avec :

- Import de classes spécifiques de `java.util`.
- Utilisation de `ArrayList` et `Scanner`.
- Import de `Arrays` pour manipuler des tableaux.
- Démonstration de l'utilisation sans conflit de noms.

## Compilation et exécution

```bash
javac Main.java
java Main
```
