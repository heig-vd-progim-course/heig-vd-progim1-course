# Exemple : Dates et heures

Cet exemple illustre l'utilisation de `java.time` avec :

- `LocalDate` pour manipuler des dates.
- `LocalTime` pour manipuler des heures.
- `LocalDateTime` pour combiner date et heure.
- `DateTimeFormatter` pour formater l'affichage.
- Calculs de durées et périodes.

## Compilation et exécution

```bash
javac Main.java
java Main
```
