# Exemple : Compte à rebours avec récursion

Cet exemple illustre le concept de récursion avec un compte à rebours simple :

- Définition d'une fonction récursive avec cas de base et cas récursif
- Comparaison entre approche itérative (boucle) et approche récursive
- Visualisation du principe "diviser pour mieux régner"
- Compréhension de la pile d'appels

La récursion est une technique où une fonction s'appelle elle-même pour résoudre
un problème en le décomposant en sous-problèmes plus simples.

## Compilation et exécution

```bash
javac Main.java
java Main
```

## Sortie attendue

L'exemple affiche trois versions du compte à rebours :

1. Version "manuelle" avec répétition de code
2. Version itérative avec une boucle `for`
3. Version récursive avec appel de fonction
