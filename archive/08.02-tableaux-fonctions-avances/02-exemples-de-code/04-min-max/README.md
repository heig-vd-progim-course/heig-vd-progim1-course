# Exemple : Recherche du minimum et du maximum

Cet exemple illustre des algorithmes de recherche de valeurs extrêmes dans un
tableau avec :

- Recherche du minimum avec `for`, `for-each`, et `while`
- Recherche du maximum avec différentes boucles
- Recherche simultanée de min et max
- Application pratique : suivi de production d'énergie solaire dans un quartier

## Compilation et exécution

```bash
javac Main.java
java Main
```
