# Exemple : Parcours avec saut d'éléments

Cet exemple illustre différentes stratégies pour parcourir un tableau en ne
traitant qu'un élément sur deux avec :

- Parcours avec accès direct par indice (`i += 2`)
- Parcours avec boucle `while`
- Parcours avec test de modulo (`i % 2`)
- Application pratique : analyse de consommation énergétique par paires
  jour/nuit

## Compilation et exécution

```bash
javac Main.java
java Main
```
