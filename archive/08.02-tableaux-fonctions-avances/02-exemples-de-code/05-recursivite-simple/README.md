# Exemple : Récursivité simple

Cet exemple illustre les principes de base de la récursivité avec :

- Factorielle récursive vs itérative
- Suite de Fibonacci récursive
- Chaîne de souhaits (exemple ludique de propagation)
- Somme récursive d'un tableau
- Comparaison récursivité/itération

## Compilation et exécution

```bash
javac Main.java
java Main
```
