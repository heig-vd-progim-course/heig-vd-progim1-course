# Exemple : Exclusion des bornes

Cet exemple illustre différentes stratégies pour parcourir un tableau en
excluant le premier et/ou le dernier élément avec :

- Exclusion de la première valeur uniquement
- Exclusion de la dernière valeur uniquement
- Exclusion des deux bornes
- Parcours avec boucle `while`
- Application pratique : élimination des valeurs extrêmes pour calculer une
  moyenne plus robuste

## Compilation et exécution

```bash
javac Main.java
java Main
```
