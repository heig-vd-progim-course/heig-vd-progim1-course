# Exemple : Recherche et comptage

Cet exemple illustre des algorithmes de recherche et de comptage dans un tableau
avec :

- Recherche linéaire simple avec différentes boucles (`for`, `while`,
  `do-while`)
- Comptage d'occurrences avec `for` classique, `for-each`, et `while`
- Application pratique : gestion des emprunts dans une bibliothèque de quartier

## Compilation et exécution

```bash
javac Main.java
java Main
```
