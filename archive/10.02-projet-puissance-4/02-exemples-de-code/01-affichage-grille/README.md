# Exemple : Affichage de la grille

Cet exemple illustre la première étape du projet Puissance 4 avec :

- Création d'un tableau 2D pour représenter la grille (6 lignes × 7 colonnes)
- Initialisation de toutes les cases à vide
- Affichage formaté de la grille avec bordures
- Numérotation des colonnes pour aider le joueur

## Compilation et exécution

```bash
javac Main.java
java Main
```
