# Exemple : Placement d'un pion

Cet exemple illustre le placement d'un pion dans la grille avec :

- Demande de colonne au joueur via Scanner
- Validation de l'entrée (colonne entre 1 et 7)
- Implémentation de la gravité (le pion tombe au plus bas)
- Vérification que la colonne n'est pas pleine
- Affichage de la grille après placement

## Compilation et exécution

```bash
javac Main.java
java Main
```
