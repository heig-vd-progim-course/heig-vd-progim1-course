## Documentation de référence

- [Documentation Java (Oracle)](https://docs.oracle.com/en/java/javase/) - la
  référence officielle, aride mais exacte.
- [Java, the Complete Reference sur dev.java](https://dev.java/learn/) - les
  tutoriels officiels, plus abordables.
- [MDN Web Docs](https://developer.mozilla.org/fr/) - pour tout ce qui touche
  au web, et un modèle de ce qu'est une bonne documentation.

## Diagrammes

- [Spécification UML (OMG)](https://www.omg.org/spec/UML/) - la référence
  complète. À consulter pour vérifier un point précis, jamais à lire.
- [PlantUML](https://plantuml.com/fr/activity-diagram-beta) - pour produire des
  diagrammes d'activité à partir de texte, une fois que vous savez les
  dessiner à la main.
- [Mermaid](https://mermaid.js.org/) - alternative à PlantUML, utilisée sur ce
  site.

## Apprendre

- [Learning How to Learn](https://www.coursera.org/learn/learning-how-to-learn)
  - cours en ligne gratuit sur les mécanismes de l'apprentissage.
- Dunlosky, J. et coll., _Improving Students' Learning With Effective Learning
  Techniques_, 2013.

## La suite de votre formation

- **ProgIM2** poursuit avec la programmation orientée objet, les références,
  les tests, et l'utilisation de bibliothèques externes avec Maven.
- Le cours
  [DAI](https://github.com/heig-vd-dai-course/heig-vd-dai-course) de la
  filière TIC est une bonne référence pour aller plus loin sur l'outillage
  Java.

## Contribuer à ce cours

Ce site est ouvert. Une faute, une explication obscure, un exemple qui ne
compile pas : ouvrez une
[issue](https://github.com/heig-vd-progim-course/heig-vd-progim1-course/issues).

Si vous savez déjà le corriger, ouvrez une pull request. C'est une excellente
première contribution à un projet libre, et cela figurera sur votre profil
public.
