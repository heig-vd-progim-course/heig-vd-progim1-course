## Intention

Mélanger, puis ranger. Le code secret est enfin secret : l'ordinateur le tire au
hasard. Et le jeu garde le classement des parties, trié du meilleur score au
moins bon.

## Objectifs pressentis

À la fin de cette séance, la personne qui étudie devrait être capable de :

- tirer un nombre entier au hasard entre deux bornes ;
- expliquer pourquoi un programme qui utilise le hasard est plus difficile à
  tester ;
- trier un tableau à la main, en suivant un algorithme de tri simple ;
- trier un tableau avec la bibliothèque standard.

## Le code secret à cette séance

Le code est tiré au hasard. Après chaque partie, le nombre d'essais est ajouté
au classement, qui s'affiche trié.
