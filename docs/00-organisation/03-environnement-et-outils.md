## Ce dont vous avez besoin

Pour la première séance : un crayon, du papier, et votre ordinateur portable
avec votre téléphone. Rien d'autre. Nous n'écrirons pas de code Java avant la
séance 04.

Pour la suite du semestre :

- un ordinateur portable sur lequel vous pouvez installer des logiciels ;
- un JDK (Java Development Kit), version 17 ou supérieure ;
- un éditeur de code : Visual Studio Code ou IntelliJ IDEA Community Edition ;
- un compte GitHub, créé avec une adresse que vous garderez après vos études.

Les instructions d'installation détaillées sont données en séance 04. Ne les
anticipez pas seul si vous n'êtes pas à l'aise : nous le ferons ensemble.

## Le terminal

Vous allez devoir lancer des commandes dans un terminal. Ce n'est pas une
formalité : savoir où vous êtes dans l'arborescence des fichiers et comment y
naviguer évite la moitié des blocages des premières semaines.

Les commandes utiles sont peu nombreuses :

| Commande | Ce qu'elle fait                                  |
| :------- | :----------------------------------------------- |
| `pwd`    | Affiche le dossier dans lequel vous vous trouvez |
| `ls`     | Liste le contenu du dossier courant              |
| `cd`     | Change de dossier                                |
| `cd ..`  | Remonte d'un niveau                              |

Sous Windows, PowerShell accepte ces commandes.

## Outils d'intelligence artificielle

### Ce qui est autorisé

Tout, tout le temps, sauf pendant les évaluations.

Il serait absurde de vous en priver : vous les utiliserez dans votre travail.
Mais il serait tout aussi absurde de vous laisser croire qu'ils remplacent la
compréhension.

### Pourquoi c'est un piège en première année

Un outil d'intelligence artificielle produit du code qui a l'air correct. En
première année, vous n'avez pas encore les moyens de distinguer du code correct
d'un code qui a l'air correct. Vous allez donc rendre du code que vous ne
pouvez pas déboguer, dans un langage que vous ne connaissez pas encore, pour un
problème que vous n'avez pas analysé.

Le résultat observable, chaque année : les personnes qui s'appuient sur ces
outils dès le début avancent plus vite les quatre premières semaines et se
bloquent complètement à la sixième.

### Un usage qui fonctionne

- Demander l'explication d'un message d'erreur que vous ne comprenez pas.
- Demander une explication d'un concept, puis vérifier dans la documentation.
- Faire relire du code que vous avez écrit et compris.

### Un usage qui ne fonctionne pas

- Demander la solution d'un exercice.
- Coller un énoncé et rendre la réponse.
- Demander du code que vous n'auriez pas pu écrire vous-même.

### Ce que vous devez déclarer

Dans tout rendu : quand, pourquoi et comment vous avez utilisé une aide
extérieure, que ce soit un outil d'intelligence artificielle, un site Internet
ou une autre personne. Cette déclaration ne coûte aucun point. Son absence,
oui.

## Attention et concentration

La programmation demande de tenir un raisonnement sur plusieurs minutes
d'affilée. Une notification coûte bien plus que les trois secondes qu'elle
occupe : elle vide la mémoire de travail dans laquelle vous teniez l'état de
votre programme.

Des outils pour reprendre la main sont proposés et installés ensemble en séance
01, sur la page
