## Ce cours en une phrase

Apprendre à décrire précisément ce que l'on veut qu'une machine fasse, puis à
l'écrire dans un langage qu'elle comprend.

## Objectifs généraux

À l'issue de cette unité d'enseignement, la personne qui étudie sera capable
de :

- décrire un problème réel sous forme d'un enchaînement d'actions, de choix et
  de répétitions ;
- représenter cet enchaînement sous forme de diagramme et de pseudo-code ;
- traduire cette description en un programme Java correct et lisible ;
- utiliser les variables, les constantes, les types de base, les structures de
  contrôle, les fonctions et les tableaux ;
- tester et déboguer un programme simple ;
- expliquer ce que fait son propre code et pourquoi elle l'a écrit ainsi.

La dernière ligne n'est pas un ornement : c'est le critère qui décide de la
note du mini-projet.
